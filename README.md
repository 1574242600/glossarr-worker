# Glossarr Worker

A [Cloudflare Worker](https://developers.cloudflare.com/workers/) rewrite of [Glossarr](https://github.com/matt-rgx/Glossarr) `proxy.js` in TypeScript. It sits transparently between Sonarr and [Skyhook](https://skyhook.sonarr.tv/v1/tvdb/), intercepting metadata requests and replacing show titles/overviews with translations from [TheTVDB](https://thetvdb.com) — in your language.

## Integrating with Sonarr

Point Sonarr at this worker via the [SonarrPatcher](https://github.com/1574242600/SonarrPatcher) SkyHook patch, which rewrites Sonarr's Skyhook base URL to `https://{your-worker}/v1/tvdb/{route}/{language}/`. Set `SKYHOOK_HOST` to your worker URL (e.g. `glossarr.youraccount.workers.dev`) and `SKYHOOK_LANG` to one of the supported `LANG` codes (e.g. `fra`).

## Features

- **Transparent proxy** for Sonarr's Skyhook traffic (`/v1/tvdb/shows/...`, `/v1/tvdb/search/...`, and any other route)
- **Show title & overview translation** via TVDB, with per-field modes: `always`, `never`, or `native`
- **Path-based language routing** — the language is a route param (`/v1/tvdb/shows/:lang/:tvdbId`) instead of an env var
- **`eng` passthrough** — requests in English return the Skyhook response unmodified
- **Search truncation** — search results are limited to 5 items before translating, avoiding sub-request limits
- **Caching everywhere** — all upstream GETs (Skyhook + TVDB) use Cloudflare's `cf` cache (5 min default), and the TVDB token is shared across isolates via a KV namespace

## Removed from the original Glossarr

- SSL/TLS (certificate generation, HTTPS server) — not needed on Workers
- Anime support (AniList / Kitsu)
- TMDB support
- Season & episode translation
- `LANGUAGE` env var (now a route param)
- `PRIMARY/SECONDARY_TRANSLATION_SOURCE` (TVDB is the only source)

## Getting started

Deploy the worker to production with one click:

[![Deploy to Cloudflare Workers](https://deploy.workers.cloudflare.com/button)](https://deploy.workers.cloudflare.com/?url=https://github.com/1574242600/glossarr-worker)

Your worker is now live, e.g. `https://glossarr-worker.<your-account>.workers.dev`.

## Environment Variables

| Variable             | Default  | Description                                        |
| -------------------- | -------- | -------------------------------------------------- |
| `TVDB_API_KEY`       | —        | TVDB v4 API key (secret)                           |
| `SHOW_TITLE_MODE`    | `native` | `always` \| `never` \| `native`                    |
| `SHOW_OVERVIEW_MODE` | `always` | `always` \| `never` \| `native`                    |
| `CACHE_TTL_SECONDS`  | `300`    | Cache TTL for Skyhook/TVDB upstream fetches (s)    |

`native` means "translate only if the show's original language matches the requested `lang`".


## Development

### Project layout

```
glossarr-worker/
├── src/
│   ├── index.ts       # itty-router routes + handlers
│   ├── config.ts      # Env bindings, LANG validation set, mode parsing
│   ├── cache.ts       # cachedFetch() — cf cacheEverything + cacheTtl
│   ├── skyhook.ts     # cached Skyhook fetches, search truncation
│   ├── tvdb.ts        # TVDB token (KV-cached, single-flight) + translation
│   ├── translate.ts   # isNativeLanguage + applyShow
│   └── types.ts       # Skyhook resource types
├── test/
│   └── index.test.ts  # smoke tests
├── vitest.config.ts
├── wrangler.jsonc
├── worker-configuration.d.ts   # generated by `pnpm types`
└── package.json
```


### Install

```bash
pnpm install
```

### Configuration

Create `.dev.vars` from the example and fill in your key (used only by the local dev server):

```bash
cp .dev.vars.example .dev.vars
# TVDB_API_KEY="your_tvdb_api_key"
```

### Local development

```bash
pnpm dev        # starts `wrangler dev` (port 8787 by default)
```

The KV namespace `GLOSSARR` is emulated locally by Wrangler/Miniflare.

### Tests

```bash
pnpm test       # vitest smoke tests
pnpm typecheck  # tsc --noEmit
```
